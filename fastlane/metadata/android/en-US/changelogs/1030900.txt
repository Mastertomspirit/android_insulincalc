# InsulinRechner 1.3.9

## What's New & Bug Fixes

- **Non-Negative Insulin Calculation:** The insulin calculator now ensures that total insulin dosages are clamped to a minimum of `0.0` IE (preventing negative values such as `-0.5` IE when small meals are combined with low blood glucose correction reductions in calculations and logbook entries).
- **AI Meal Query State Persistence:** Fixed input query state retention in `AiMealEstimatorScreen` during screen rotations by replacing `remember` with `rememberSaveable`.
- **Gemini API:** Adjusted connection timeouts for long AI responses.
- **AI Estimator:** Updated example strings with precise portion sizes (g/ml) and refreshed meal choices.
- **Localization Fixes:** Corrected plural string placeholders for logbook entry counts (`logbook_entry_count`).
- **AI Configuration & Theme Stability:** Fixed a crash (NullPointerException) during AI configuration saves when theme preferences are uninitialized.
- **Comprehensive UI Test Suite:** Added automated UI tests covering the core sections (Calculator, AI, Logbook, and Settings).
- **Build Automation:** Introduced the new `updateReadme` Gradle task to automatically synchronize version numbers in the `README.md`.
